# e-plantShopping

## Project Name

e-plantShopping

## Description

e-plantShopping is a React-based plant shopping application that allows users to browse plants, add products to a shopping cart, update quantities, and remove items from the cart.

## Technologies Used

- React
- Redux Toolkit
- React Redux
- Vite
- JavaScript
- CSS

## Features

- Browse plants by category
- View plant details
- Add plants to the cart
- Increase or decrease product quantities
- Remove products from the cart
- View total cart quantity
- View total cart amount
- Continue shopping
- GitHub Pages deployment
